# packet-tracer-network-project
Cisco Packet Tracer — Secure Two-Site Enterprise Network

Designed and simulated a secure enterprise network connecting two company sites using Cisco Packet Tracer.

Key Features

VLAN segmentation: Separated administrators, wired employees, guests, wireless employees, and VoIP devices into dedicated VLANs.

Inter-site connectivity: Configured a GRE tunnel between the two sites and secured communications using IPsec VPN.

Network security: Implemented SSH for secure device management and restricted guest access to SSH.

Wireless networking: Configured wireless access for employees and guests, including WPA2-PSK and RADIUS-based AAA authentication.

Network services: Configured DHCP, a Wireless LAN Controller (WLC), and TFTP for network configuration backups.

Routing and connectivity: Used inter-VLAN routing, OSPF, and static routing to support communication between networks and internet access.

Skills Demonstrated

Cisco networking, VLANs, subnetting, routing, GRE tunneling, IPsec VPN, SSH, wireless networking, RADIUS/AAA, DHCP, and network troubleshooting.
